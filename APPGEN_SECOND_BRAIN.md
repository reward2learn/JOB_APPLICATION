## Recent decisions (2026-10-24 — Narrative Architect evidenceIds coerce)

- **Symptom:** step 3 paused — `Narrative Architect: schema violation — gapStories[0].evidenceIds Too big: expected array to have <=6 items` (Nemotron via Gateway).
- **Root cause:** Step 3 Zod-parsed LLM JSON with no coerce; models often cite >6 evidence IDs per gap story (and >8 per theme). Step 2 already truncated via `coerceEvidenceMap`.
- **Fix:** `coerceNarrative` truncates `themes` (≤8), `themes[].evidenceIds` (≤8), `gapStories` (≤8), `gapStories[].evidenceIds` (≤6) + string caps before Zod; wired into step 3 parse/retry. Unit test in `test/tailor.test.mjs`.

## Recent decisions (2026-10-19 — JD Analyst `role` coercion)

- **Symptom:** step 1 paused — `JD Analyst: schema violation — role Invalid input: expected string, received undefined`.
- **Root cause:** Nemotron sometimes omits top-level `role` or nests output under `requirements` / uses `title` instead of `role`.
- **Fix:** `coerceRequirements(parsed, jd)` on step 1 — unwrap nested roots, alias fields, `inferRoleFromJd` from first JD line; step-1 prompt marks `role` as required.
- **Prod deploy:** `dpl_5Mxo8WtptHgjYQn2KNLCra1H5qJR` → https://apply4job.vercel.app

## Recent decisions (2026-10-19 — Evidence Mapper schema backfill)

- **Symptom:** step 2 paused with `Evidence Mapper: schema violation — mappings Too small: expected array to have >=1 items` (checkpoint had valid R1–R8 / D1–D6 requirements).
- **Root cause:** Nemotron sometimes returns `{"mappings":[]}`, uses `mapping` / `id` instead of `mappings` / `requirementId`, or rows with no id — `coerceEvidenceMap` dropped all rows before Zod `.min(1)`.
- **Fix:** `coerceEvidenceMap(parsed, requirements)` + `fillMissingEvidenceMappings` (one row per requirement id; missing → honest `gap`); clearer step-2 prompt (must cover every R/D id).
